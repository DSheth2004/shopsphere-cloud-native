    Platform status

    Live health of every microservice, checked through the API gateway.

    How a request flows

    1. Browser → Frontend (nginx) serves this UI and proxies /api.
    2. API Gateway validates the JWT, rate-limits sign-in and routes to the right service.
    3. Auth (PostgreSQL), Product (MongoDB), Cart (Redis), Order and Inventory each own their data.
    4. RabbitMQ carries saga events between Order, Inventory, Payment and Notification.
    5. Everything ships as Docker images, built and scanned in GitHub Actions and deployed to Kubernetes.
